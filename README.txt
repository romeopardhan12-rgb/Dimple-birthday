DIMPLE BIRTHDAY WEBSITE 💕
===========================

Files:
- index.html
- style.css
- script.js

MUSIC:
The website has a Play our song button prepared for "Tum Se".
Because the song is copyrighted, no music file is included.
If you have the right to use an audio copy, rename it to:
    tum-se.mp3
and put it in the same folder as index.html.

FREE PUBLISHING:
1. Create a free GitHub account at github.com.
2. Create a new public repository, e.g. "dimple-birthday".
3. Upload index.html, style.css, script.js and (if you have permission) tum-se.mp3.
4. In the repository, open Settings > Pages.
5. Choose "Deploy from a branch", select "main" and "/ (root)", then Save.
6. GitHub will give you a free website address you can send to Dimple.

You can also open index.html directly on your computer/phone to preview it.
